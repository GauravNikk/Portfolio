## Hero visual

Do not use a stock device mockup.

Create a live composition from real project assets.

```text
                REAL SCREENSHOT
                      │
        ┌─────────────┴─────────────┐
        │                           │
   MOBILE DEVICE              MOBILE DEVICE
        │                           │
        └─────────────┬─────────────┘
                      │
                ENGINEERING
                   SIGNAL
```

The screenshots should come from the actual Play Store assets extracted for the portfolio.

## Hero animation

At initial load:

1. Typography enters first.
2. A thin engineering line draws from left to right.
3. Device frames rise from the bottom.
4. Real screenshots settle into place.
5. Metric labels appear last.

Do not animate the entire page simultaneously.
