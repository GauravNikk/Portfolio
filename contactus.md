# Contact Page Visual

Avoid:
- giant envelope illustration
- generic contact stock art
- animated paper-plane graphics

Instead use a simple technical "handoff" visual:

```text
YOUR IDEA
    │
    ▼
┌──────────────┐
│ REQUIREMENT  │
└──────────────┘
    │
    ▼
┌──────────────┐
│ ENGINEERING  │
└──────────────┘
    │
    ▼
┌──────────────┐
│ SHIPPED      │
└──────────────┘
```

This reinforces the product-engineering identity.

---

# Contact Animation

When the page loads:
- contact information enters from the left
- form enters from the right
- a thin line connects them

On successful submit:
- do not use confetti
- transform the form into a calm success state

---

# Privacy

Do not expose:
- API keys
- private client data
- personal project credentials

Add a small privacy statement below the form.
